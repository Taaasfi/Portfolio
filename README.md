# Tasfia Nasrin Mim — Portfolio

A responsive one-page portfolio built from the information in the supplied CV.

## Run locally
Open `index.html` in a browser.

## Customize
- Replace the project visual placeholders with real screenshots.
- Add live project URLs to the project cards.
- Add a PDF CV link if desired.
- Deploy the folder to GitHub Pages, Netlify, Vercel, or any standard web host.

The portfolio intentionally avoids inventing project metrics/results that were not present in the CV.
